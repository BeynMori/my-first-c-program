# Моя первая программа на языке C! 🚀

Привет! Я учусь работать в командной строке Linux (Ubuntu WSL) по книге Уильяма Шоттса.

В рамках эксперимента я успешно написал код на C, скомпилировал его с помощью компилятора `gcc` и запустил в терминале.
